# Dev Patel — Portfolio

A modern, responsive personal portfolio website built with the **MERN stack** frontend tooling (React + Vite). It showcases my skills, featured projects, certificates, achievements, and contact information in a polished, animated, dark/light theme.

## 🚀 Tech Stack

- **React 19** — UI components with hooks
- **Vite** — fast dev server & optimized production builds
- **Tailwind CSS 4** — utility-first styling
- **Framer Motion** — smooth scroll/entrance animations
- **React Router** & **React Helmet Async** — navigation & SEO meta
- **react-icons** — icon library
- **EmailJS** — contact form email delivery

## ✨ Features

- Animated hero with rotating role text & particle background
- About, Skills, Projects, Certificates, Achievements, and Contact sections
- Filterable projects grid with tech tags & GitHub links
- Dark / light theme toggle
- Fully responsive for desktop, tablet & mobile
- Resume download link

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview

# Lint
npm run lint
```
